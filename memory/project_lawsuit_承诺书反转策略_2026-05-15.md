## 承诺书攻击点的反转策略（2026-05-15）

### 风险背景
被告律师在5/12庭审已埋伏笔，第二回合大概率攻击：
- 2018年签入住承诺书 → "已阅读住户手册" → 住户手册"按运行成本收取" → 原告已认可定价方式
- 配合7年付费 → 行为追认 → 禁反言

### 核心战术（不要硬刚说承诺书无效）

**核武器：反向使用承诺书**——承认有效，但用它反打：
- 被告自己违反"按运行成本收取"
- 节能分成不是成本（5/12-13被告6处自爆已坐实）
- 评估报告显示扣除分成后实际成本 < 42元
- "原告不是挑战承诺书，原告是在执行承诺书"

### 八层反驳储备
1. 反向使用（核武器）
2. 范围严格限定（与2003承诺书策略一致）
3. 上位法穿透（住户手册≠管理规约）
4. 格式条款审查（民法典496-498）
5. 意思表示瑕疵（民法典147/148）
6. 行为不构成追认（知情时点2024-06）
7. 三层逻辑链拆分
8. 禁反言反向适用

### 法官最可能的中间判决路径
"承诺书有效，但收费应回归实际运行成本，被告退还分成部分。"
→ **核武器反转正好对应这条路径**，部分胜诉可接受。

### 当庭必做两件事
1. 要求被告出示承诺书 + 住户手册原件（5/12援引未出示）
2. 要求被告举证住户手册的业主大会通过文件
