## 核心策略

听律师的——交证据。但不按典型框架用——不证明"服务不好所以少付"，证明"我是理性克制的业主，暂停缴费有因有据"。

## 交什么 vs 不交什么

| 交（高价值） | 不交（陷阱） |
|-------------|-------------|
| 12345工单（最优——第三方平台可核验） | 保洁、保安问题孤立照片 |
| 给物业的书面质疑/投诉 | 地不干净、灯坏了的随手照 |
| 微信/邮件沟通记录 | 偶发性单一事件 |
| 22个月沟通时间线汇总 | 无法标注时间的材料 |
| 现场照片（仅当与上述沟通记录构成闭环时） | 无对应沟通记录的照片 |

## 闭环4要素（缺一不可）

1. ① 服务问题客观记录（带时间戳）
2. ② 答辩人书面反映记录（12345/微信/邮件/信函）
3. ③ 物业回应情况（物业书面回应原文 OR "未作出书面回应"）
4. ④ 后续整改状态（"至今未整改"最有力）

## 严控用途——必须配独立护栏段落

提交时附明确声明：
> "本说明所附证据**不用于主张物业费酌减**——答辩人对22个月物业费本金愿意全额支付。提交目的是证明：服务问题客观存在 → 答辩人反复书面反映 → 反诉原告未作出书面回应 → 暂停支付物业费具有客观背景与正当原因 → **不构成恶意拖欠**。"

护栏段落是整份证据材料的命门——没有它，对方律师可把证据反向利用为"业主主张服务质量纠纷"，案件性质漂移。

## 5项以内严选

不是越多越好。挑跨期长、反复反映、物业未整改、有书面留痕的5项以内。涵盖至少3类不同问题（公共设施/账目透明度/秩序卫生/沟通响应/安全），避免"挑刺单点"。

**Why:** 律师的直觉"需要服务不到位的证据"是对的，但典型用法（提交服务瑕疵→要求减免物业费）会稀释热水产权核心战场。调整证据类型（沟通记录主导、服务瑕疵辅助）+ 论证方向（证明理性而非砍价）+ 护栏声明（锁死用途），既满足了律师的建议，又不偏离战略目标。

**How to apply:** 所有涉及"服务"的证据提交，必须带护栏段落明确"不主张酌减"。庭上话术："这些证据不是要证明服务不好所以少付费——物业费愿意支付。这些证据是说明：暂停缴费是在长期反复沟通未获回应后的克制行为。"
